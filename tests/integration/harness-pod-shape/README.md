# harness-pod-shape/

Harness pods (labeled `app.kubernetes.io/part-of=sycophant` +
`component=harness`) must conform to a strict shape enforced by the
`cluster-gvisor-pod-policy` VAP. One test per CEL expression, plus a
happy-path admit test.

Tenant namespaces are created via the deployer SA so the per-tenant
VAPBinding is generated by Kyverno before the test pod submits. If the
VAPBinding is missing, the VAP cannot fire — the test must catch that as a
red, not silently admit.

Belongs here: any constraint the VAP enforces on harness-labeled pods.
Doesn't belong here: PSA-driven rejections (see `privileged-workload-rejection/`),
non-pod resources.
